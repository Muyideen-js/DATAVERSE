# 🌟 DATAVERSE

**Transform Data Into Intelligence**

DATAVERSE is an AI-powered data analysis platform that turns your CSV files into actionable insights through natural language queries. Upload your data, ask questions in plain English, and watch as intelligent visualizations are generated instantly—no coding required.

![DATAVERSE Banner](https://img.shields.io/badge/AI-Powered-black?style=for-the-badge) ![React](https://img.shields.io/badge/React-18-61DAFB?style=for-the-badge&logo=react) ![Vite](https://img.shields.io/badge/Vite-5-646CFF?style=for-the-badge&logo=vite)

## ✨ Features

### 🤖 AI-Powered Analysis
- **Natural Language Queries**: Ask questions in plain English
- **Smart Visualizations**: Automatically selects the best chart type
- **Real-time Insights**: Get instant analysis as you explore your data

### 📊 Intelligent Visualizations
- **Line Charts**: Trend analysis over time
- **Bar Charts**: Compare values across categories
- **Pie Charts**: Distribution and composition analysis
- **Data Tables**: Searchable, paginated data views
- **Statistics Cards**: Key metrics at a glance
- **Anomaly Detection**: Identify outliers and unusual patterns

### 🎨 Modern UI/UX
- **Clean White Theme**: Professional, distraction-free interface
- **Real-time Updates**: Live clock and data statistics
- **Responsive Design**: Works seamlessly on all devices
- **Smooth Animations**: Powered by Framer Motion
- **3D Physics**: Interactive lanyard component with React Three Fiber

### 🔍 Advanced Data Table
- **Search Functionality**: Search across all fields instantly
- **Pagination**: Navigate through thousands of rows efficiently
- **Real-time Filtering**: Results update as you type
- **Smart Counter**: Shows filtered vs total records

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/dataverse.git

# Navigate to project directory
cd dataverse

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to see DATAVERSE in action!

## 📖 Usage

1. **Upload Your Data**: Drag and drop a CSV file or browse to select
2. **Ask Questions**: Type natural language queries like:
   - "Show revenue trends over time"
   - "Compare sales by region"
   - "Find anomalies in the data"
   - "Show me the data table"
3. **Get Insights**: DATAVERSE automatically generates the perfect visualization
4. **Explore**: Search, filter, and paginate through your data

## 🛠️ Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Vanilla CSS (no frameworks)
- **Animations**: Framer Motion + GSAP
- **3D Graphics**: React Three Fiber + Rapier Physics
- **Charts**: Recharts
- **Data Parsing**: PapaParse
- **Routing**: React Router DOM
- **Icons**: React Icons

## 🎯 Key Components

- **Smart Component Selector**: AI-powered visualization selection
- **Real-time TopBar**: Live clock and data statistics
- **Interactive Data Table**: Search, filter, and paginate
- **Insights Panel**: Auto-generated insights and metrics
- **Physics-based Lanyard**: 3D interactive brand element
